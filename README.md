## ✨ Key Highlights & Features

- 🎬 **Auto-Muxing Engine (Full Audio & Video)**:
  Never get a silent video again. Bundles an auto-managed `FFmpeg` muxer that merges separated high-res video and audio streams into clean `.mp4` files.

- 🎵 **Spotify to 320kbps MP3 Converter**:
  Paste any Spotify track URL — the app resolves track titles, artist names, and album artwork, saving crisp **320kbps MP3s**.

- 📊 **Multi-Task Download Queue**:
  Download up to 10 files simultaneously with live speed meters (`MB/s`), dynamic ETA countdowns, pause, resume, and retry controls.

- 📋 **Smart Clipboard Detection**:
  Automatically detects when you copy a video link in your web browser and prompts you for an instant 1-click download.

- 🎨 **Dark & Light Mode UI**:
  A sleek, modern Windows Fluent interface with smooth animations and instant theme switching.

- 📜 **Download History Archive**:
  Easily browse past downloads, search by title, and open files or folders directly in Windows Explorer.

## 🚀 Quick Start Guide

1. **Download** the latest release from the [Releases Page](https://github.com/Mouataz86/aio-download-manager/releases/latest).
2. **Run** `AIO Download Manager Setup 1.0.0.exe` (or use the Portable edition).
3. **Copy any video link** from YouTube, TikTok, Facebook, or Spotify.
4. Click **New Download** ➔ Select Quality (4K, 1080p, or MP3) ➔ Click **Download Now**!
